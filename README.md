# Паника-режим

## О проекте

«Паника-режим» — это простое веб-приложение, которое помогает пользователю разобраться со сложной или стрессовой ситуацией.

Пользователь выбирает тип ситуации, описывает проблему и получает пошаговый план действий.

## Цель проекта

Помочь пользователю быстро определить ближайшие действия в сложной ситуации.

## Основные функции

- Выбор типа ситуации
- Ввод описания проблемы
- Получение пошагового плана
- Проверка пустых полей
- Возможность начать заново

## Типы ситуаций

В проекте доступны четыре ситуации:

1. Учёба
2. Стресс
3. Конфликт
4. Другая ситуация

## Технологии

Проект создан только с использованием:

- HTML
- CSS
- JavaScript

Фреймворки и библиотеки не используются.
